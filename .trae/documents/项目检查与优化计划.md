# 项目检查与优化计划（全面版）

## 1. 代码质量检查与修复
- 使用 `ruff --fix` 命令自动修复 `evaluator.py` 文件中的空白行包含空格问题
- 运行 `ruff check src/` 确保所有代码符合 PEP 8 规范
- 检查所有文件的行长度，确保不超过 88 字符
- 确保变量名、类名、函数名符合命名规范

## 2. 日志规范检查
- 检查所有代码文件，确保使用 `from network_simulation.utils.logger import get_logger` 导入日志模块
- 确保所有代码使用 `logger.info()/debug()/warning()/error()` 而不是 `print()` 语句
- 检查日志内容，确保包含足够的上下文信息
- 确保日志级别使用正确，DEBUG 用于调试信息，INFO 用于正常运行信息，WARNING 用于警告信息，ERROR 用于错误信息

## 3. 文件路径规范检查
- 检查所有代码文件，确保使用 Path 对象处理文件路径
- 确保所有文件路径符合项目目录结构规范
- 检查临时文件，确保存放在 `tmp/` 目录下
- 确保持久化文件存放在固定目录，不使用临时目录

## 4. 注释规范检查
- 检查所有核心函数，确保添加了完整的文档字符串
- 检查文档字符串格式，确保符合中文谷歌风格注释规范
- 检查行内注释，确保简洁明了，解释复杂代码的逻辑
- 检查文件注释，确保包含文件功能描述、作者、创建日期、版本等信息
- 确保注释与代码保持一致，删除过时的注释

## 5. 可视化规范检查
- 检查所有可视化代码，确保添加了跨平台中文支持配置
- 确保所有可视化输出使用高分辨率（DPI ≥ 300）
- 检查可视化文件名，确保符合 `{功能}_{描述}_{日期时间戳}.png` 格式
- 检查丢包率相关的可视化，确保将丢包率范围限制在 0-1 之间
