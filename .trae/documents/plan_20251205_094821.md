## 生成样本质量改进方案（统一窗口配置）

### 问题分析
1. **窗口配置统一问题**：当前所有脚本已从config.py加载统一的窗口参数（窗口大小100，滑动步长50），但生成结果仍不理想
2. **行为类别过多**：HDBSCAN生成26个类别，而非预期的0-9，导致模型难以学习
3. **样本组单一类别**：样本组选择逻辑倾向于选择单一行为类别的序列
4. **生成数据质量差**：时延负值，丢包率分布不合理

### 改进方案

#### 1. 调整HDBSCAN参数，控制行为类别数量
- 修改config.py中的HDBSCAN参数，增加min_cluster_size和min_samples
- 确保生成的行为类别数量控制在合理范围（0-9）

```python
# 修改config.py中的HDBSCAN参数
# 增加min_cluster_size和min_samples，减少生成的类别数量
DEFAULT_MIN_CLUSTER_SIZE = 15  # 从3增加到15
DEFAULT_MIN_SAMPLES = 5        # 从1增加到5
DEFAULT_CLUSTER_SELECTION_EPSILON = 0.3  # 增加epsilon，放宽聚类条件
```

#### 2. 确保所有脚本使用统一的窗口参数
- 验证所有脚本都从config.py加载窗口参数
- 确保特征提取、行为标签生成和样本生成使用相同的窗口配置

```python
# 检查所有脚本的窗口参数加载
# 确保feature_extractor.py、step2_0_preprocess_data.py等都从config.py加载参数
# 例如在feature_extractor.py中
from ...config import DEFAULT_WINDOW_SIZE, DEFAULT_STRIDE
self.window_samples = DEFAULT_WINDOW_SIZE
self.slide_samples = DEFAULT_STRIDE
```

#### 3. 改进样本组选择逻辑
- 降低主要行为类别比例阈值，允许样本组包含多个类别
- 确保每组样本覆盖不同的行为组合
- 避免单一类别样本组

```python
# 修改step2_2_generate_samples.py中的样本组选择逻辑
# 1. 降低主要行为类别比例阈值到0.3
if main_behavior_ratio >= 0.3 and main_behavior not in group_behavior_types:
    start_indices.append(idx)
    group_behavior_types.append(main_behavior)
    
# 2. 优先选择包含多个类别的样本组
if len(unique_current) >= 3:  # 至少包含3个不同类别
    start_indices.append(idx)
    group_behavior_types.append(f"diverse_{main_behavior}")
    print(f"找到多样化样本组 - 起始索引: {idx}, 包含 {len(unique_current)} 个类别")
    continue  # 优先使用多样化样本组
```

#### 4. 增加模型训练轮次，提高生成质量
- 增加DEFAULT_EPOCHS到100
- 调整学习率调度策略

```python
# 修改config.py中的训练参数
DEFAULT_EPOCHS = 100  # 从50增加到100
DEFAULT_LEARNING_RATE = 2e-4  # 微调学习率
```

#### 5. 优化生成样本长度
- 确保生成的样本长度与训练数据匹配
- 调整样本长度，确保行为类别变化

```python
# 修改step2_2_generate_samples.py中的样本长度
# 确保样本长度能够包含多个行为类别变化
sample_length = 6000  # 保持样本长度不变，但确保样本组包含多个类别
```

### 实施步骤
1. 修改config.py，调整HDBSCAN和训练参数
2. 确保所有脚本使用统一的窗口参数
3. 改进step2_2_generate_samples.py中的样本组选择逻辑
4. 重新运行完整流程：
   - step1_2_extract_features.py（特征提取）
   - step1_3_discover_patterns.py（行为标签生成）
   - step2_0_preprocess_data.py（数据预处理）
   - step2_1_train_model.py（模型训练）
   - step2_2_generate_samples.py（样本生成）

### 验证指标
1. 行为类别数量：控制在0-9
2. 样本组类别多样性：每组包含多个类别
3. 生成数据质量：时延非负，丢包率分布合理
4. 生成数据与原始数据分布相似度

该方案确保了统一的窗口配置，同时通过调整关键参数和改进逻辑，提高了生成样本的质量和多样性。
