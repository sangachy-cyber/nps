# 修复训练数据合并逻辑

## 问题分析

### 根本原因
1. **训练数据单一**：步骤2.0只使用了一个原始数据文件作为训练数据
2. **丢包率分布不完整**：单一文件的丢包率分布不能代表所有原始数据
3. **合并逻辑缺陷**：虽然合并了所有文件的合法丢包值，但训练数据本身只来自一个文件

### 具体分析
- **合并的合法丢包值**：[0.0, 0.2, 0.25, 0.4, 0.5, 0.6, 0.75, 0.8, 1.0]
- **但训练数据**：只来自一个文件（20251204_012208_co0-playback_processed.csv）
- **导致问题**：训练数据中的丢包率变化不足，模型无法学习完整的丢包率分布

## 解决方案

### 1. 修改步骤2.0，合并所有原始数据文件
- **修改点**：`step2_0_preprocess_data.py`中的数据加载和处理部分
- **改进内容**：
  ```python
  # 2. 加载和合并所有处理后的原始数据文件
  if input_processed_path.is_dir():
      # 如果输入是一个文件夹，合并所有处理后的文件
      processed_files = list(input_processed_path.glob("*.csv"))
      if not processed_files:
          print(f"警告: 在 {input_processed_path} 中未找到 .csv 文件")
          sys.exit(1)
      
      # 合并所有处理后的文件
      all_processed_df = []
      for processed_file in processed_files:
          df = pd.read_csv(processed_file, parse_dates=["timestamp"])
          all_processed_df.append(df)
      
      # 合并为一个DataFrame
      merged_processed_df = pd.concat(all_processed_df, ignore_index=True)
      print(f"合并了 {len(processed_files)} 个处理后的文件，总样本数: {len(merged_processed_df)}")
      
      # 使用合并后的数据作为训练数据
      valid_df = merged_processed_df
  ```

### 2. 确保训练数据包含完整的丢包率分布
- **修改点**：`step2_0_preprocess_data.py`中的数据处理部分
- **改进内容**：
  ```python
  # 检查合并后的训练数据的丢包率分布
  unique_loss_rates = np.unique(valid_df["loss_rate"].values)
  print(f"合并后训练数据丢包率唯一值: {unique_loss_rates}")
  print(f"合并后训练数据丢包率分布: {np.bincount([loss_rate_mapping[lr] for lr in valid_df['loss_rate'].values])}")
  
  # 确保训练数据包含所有合法丢包值
  missing_loss_values = [val for val in valid_loss_values if val not in unique_loss_rates]
  if missing_loss_values:
      print(f"警告: 训练数据中缺少一些合法丢包值: {missing_loss_values}")
      print("建议: 确保使用了所有原始数据文件")
  ```

### 3. 修复丢包率归一化逻辑
- **修改点**：`step2_0_preprocess_data.py`中的丢包率归一化部分
- **改进内容**：
  ```python
  # 3.2 loss_rate归一化：序数编码 + Min-Max缩放
  print("归一化丢包率值...")
  loss_rate_values = valid_df["loss_rate"].values
  
  # 执行序数编码
  loss_rate_indices = np.array([loss_rate_mapping[lr] for lr in loss_rate_values])
  
  # Min-Max缩放到[-1, 1]
  if N_vals > 1:
      # 正常缩放，不再检查唯一值数量
      # 因为合并数据后应该包含多种丢包率值
      loss_norm = (loss_rate_indices / (N_vals - 1)) * 2 - 1
  else:
      # 当只有一个有效丢包值时，直接设置为0
      loss_norm = np.zeros_like(loss_rate_indices)
  ```

### 4. 优化行为标签对齐逻辑
- **修改点**：`step2_0_preprocess_data.py`中的行为标签对齐部分
- **改进内容**：
  ```python
  # 1. 处理行为标签对齐
  # 加载行为标签（从JSON文件）
  behavior_labels_file = next(input_patterns_dir.glob("behavior_labels_*.json"))
  with open(behavior_labels_file, "r") as f:
      behavior_labels_data = json.load(f)
  behavior_ids = np.array(behavior_labels_data["labels"])
  
  # 确保行为标签与合并后的训练数据长度匹配
  # 重新计算窗口数量和步长，确保标签对齐
  window_size = 100
  stride = 50
  total_samples = len(valid_df)
  num_windows = (total_samples - window_size) // stride + 1
  
  # 确保行为标签数量与窗口数量匹配
  if len(behavior_ids) != num_windows:
      print(f"警告: 行为标签数量 {len(behavior_ids)} 与窗口数量 {num_windows} 不匹配")
      # 调整行为标签数量
      behavior_ids = behavior_ids[:num_windows]
      print(f"已调整行为标签数量为 {len(behavior_ids)}")
  ```
