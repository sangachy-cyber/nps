# 实现分位数归一化

## 目标
在现有归一化模块中添加分位数归一化支持，用于处理网络延迟数据，改善模型训练效果。

## 实现步骤

1. **修改normalization.py文件**
   - 添加分位数归一化函数
   - 修改normalize_delay函数，支持选择归一化方法
   - 更新denormalize_delay函数，支持分位数反归一化
   - 保持与现有代码的兼容性

2. **实现分位数归一化功能**
   - 实现quantile_normalize函数，将数据转换为均匀分布
   - 实现quantile_denormalize函数，还原原始数据
   - 支持将结果缩放到[-1, 1]范围

3. **测试新功能**
   - 运行端到端pipeline，验证分位数归一化的效果
   - 比较不同归一化方法的训练结果
   - 确保生成的延迟值在合理范围内

## 具体实现

### 1. 添加分位数归一化函数
```python
def quantile_normalize(data: np.ndarray) -> tuple[np.ndarray, dict]:
    """分位数归一化
    将数据转换为均匀分布，映射到[0, 1]范围
    """
    # 计算分位数
    sorted_data = np.sort(data)
    quantile_values = np.arange(1, len(data) + 1) / len(data)
    
    # 创建分位数映射
    quantile_map = {val: q for val, q in zip(sorted_data, quantile_values)}
    
    # 对原始数据进行映射
    normalized = np.array([quantile_map[val] for val in data])
    
    # 保存归一化参数
    params = {
        'sorted_data': sorted_data,
        'quantile_values': quantile_values
    }
    
    return normalized, params
```

## 风险与应对
1. **性能问题**：分位数归一化计算复杂度较高，对于大数据集可能影响性能
   - 应对：添加数据采样或近似分位数计算

2. **反归一化精度**：分位数归一化是近似的，反归一化可能存在误差
   - 应对：使用线性插值提高反归一化精度

3. **兼容性问题**：新的归一化参数格式可能与旧模型不兼容
   - 应对：保持向后兼容性，支持旧参数格式

通过实现分位数归一化，我们可以改善模型对网络延迟数据的处理效果，生成更符合实际分布的延迟值。
