# 优化 e2e pipeline 调用方式

## 目标
将 e2e pipeline 中的 `subprocess` 调用替换为直接调用各个脚本中的核心函数，减少文件I/O，提高代码可维护性和执行效率。

## 分析
1. **当前状态**：
   - `e2e_pipeline.py` 使用 `subprocess` 调用所有步骤脚本
   - `optimized_e2e_pipeline.py` 部分步骤直接调用Python模块，部分仍使用 `subprocess`
   - 各个步骤脚本都有独立的核心函数（如 `process_raw_data`、`extract_features` 等）

2. **优势**：
   - 减少进程间通信开销
   - 减少中间文件I/O
   - 提高代码复用性和可维护性
   - 便于统一管理和优化

## 实现步骤

### 1. 修改 `e2e_pipeline.py`
- 移除 `subprocess` 调用，直接导入并调用各个脚本的核心函数
- 保持原有功能不变，确保向后兼容

### 2. 修改 `optimized_e2e_pipeline.py`
- 将剩余的 `subprocess` 调用替换为直接函数调用
- 统一代码风格和调用方式

### 3. 确保各个步骤脚本的核心函数可导入
- 检查每个脚本的核心函数是否可以直接导入
- 确保函数参数和返回值设计合理

### 4. 测试优化后的流水线
- 运行优化后的流水线，确保功能正常
- 验证输出结果与原有实现一致

## 具体修改内容

### 对于 `e2e_pipeline.py`：
1. 导入各个脚本的核心函数：
   - `from step1_1_process_raw import process_raw_data`
   - `from step1_2_extract_features import extract_features`
   - `from step1_3_discover_patterns import discover_patterns`
   - `from step2_0_preprocess_data import preprocess_data`
   - `from step2_1_train_model import train_model`
   - `from step2_2_generate_samples import generate_samples`
   - `from step2_3_visualize_results import visualize_results`
   - `from step2_4_evaluate_generation import evaluate_generation`

2. 将 `run_command` 函数替换为直接函数调用

### 对于 `optimized_e2e_pipeline.py`：
1. 导入剩余步骤脚本的核心函数
2. 将 `run_subprocess` 调用替换为直接函数调用

## 预期结果
- 减少流水线执行时间（尤其是文件I/O密集型任务）
- 提高代码可维护性，便于后续优化
- 统一代码风格，减少脚本间的差异
- 保持原有功能不变，确保向后兼容
