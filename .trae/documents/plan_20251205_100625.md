## 时延归一化改进方案（鲁棒性归一化+[-1, 1]缩放）

### 问题分析
1. **当前归一化逻辑**：
   - 使用RobustScaler(quantile_range=(1, 99))
   - 保留原始输出，不进行额外范围调整
   - 归一化后的值可能超出[-1, 1]范围
   - 导致模型学习到不合理的特征分布

2. **用户要求**：
   - 继续使用鲁棒性归一化（RobustScaler）
   - 在归一化后将值缩放到[-1, 1]范围
   - 不使用后处理
   - 解决生成时延负值问题

3. **核心解决方案**：
   - 在RobustScaler归一化后添加缩放步骤，将值映射到[-1, 1]
   - 确保反归一化后的值合理

### 改进方案

#### 1. 改进归一化逻辑（step2_0_preprocess_data.py）
- 继续使用RobustScaler
- 添加缩放步骤，将归一化后的值映射到[-1, 1]范围
- 保存缩放参数，用于反归一化

```python
# 修改step2_0_preprocess_data.py中的归一化逻辑
# 1. 继续使用RobustScaler
delay_scaler = RobustScaler(quantile_range=(1, 99))
delay_values = valid_df["delay"].values.reshape(-1, 1)
delay_scaled = delay_scaler.fit_transform(delay_values).flatten()

# 2. 将RobustScaler输出缩放到[-1, 1]范围
# 计算当前归一化后的最小值和最大值
current_min = np.min(delay_scaled)
current_max = np.max(delay_scaled)

# 保存缩放参数
robust_scale_min = current_min
robust_scale_max = current_max

# 映射到[-1, 1]范围
if current_max > current_min:
    delay_norm = 2 * ((delay_scaled - current_min) / (current_max - current_min)) - 1
else:
    delay_norm = np.zeros_like(delay_scaled)

# 3. 保存缩放参数到preprocess_data.npz
np.savez(
    npz_file,
    # ... 其他参数 ...
    robust_scale_min=robust_scale_min,
    robust_scale_max=robust_scale_max,
    # ... 其他参数 ...
)
```

#### 2. 改进反归一化逻辑（step2_2_generate_samples.py）
- 添加逆向缩放步骤，先从[-1, 1]映射回RobustScaler的输出范围
- 然后应用RobustScaler的反变换

```python
# 修改step2_2_generate_samples.py中的反归一化逻辑
# 1. 加载缩放参数
robust_scale_min = checkpoint.get("robust_scale_min", np.min(delay_norm))
robust_scale_max = checkpoint.get("robust_scale_max", np.max(delay_norm))

# 2. 从[-1, 1]逆向缩放到RobustScaler输出范围
if robust_scale_max > robust_scale_min:
    # 先从[-1, 1]映射到[0, 1]
    mapped_to_01 = (delay_norm + 1) / 2
    # 再从[0, 1]映射到RobustScaler的输出范围
    delay_scaled_reconstructed = mapped_to_01 * (robust_scale_max - robust_scale_min) + robust_scale_min
else:
    delay_scaled_reconstructed = delay_norm

# 3. 应用RobustScaler反变换
delay = (delay_scaled_reconstructed * delay_scaler_scale_) + delay_scaler_mean_
```

#### 3. 优化模型训练（diffusion_model.py）
- 确保模型学习到合理的特征分布
- 在sample方法中添加约束，确保生成的特征在[-1, 1]范围内

```python
# 修改diffusion_model.py中的sample方法
def sample(self, behavior_ids, device):
    # 生成样本
    generated = super().sample(behavior_ids, device)
    
    # 确保生成的特征在[-1, 1]范围内
    generated = torch.clip(generated, -1, 1)
    
    return generated
```
