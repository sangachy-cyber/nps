# 修复归一化与反归一化不匹配问题

## 问题分析

### 根本原因
1. **归一化逻辑不匹配**：训练时使用RobustScaler，生成时使用假设范围为[-1, 1]的反归一化公式
2. **训练数据归一化范围**：训练数据的时延归一化后范围是[-0.5309, 49.5340]，远超[-1, 1]范围
3. **生成数据范围受限**：反归一化公式`delay = (delay_norm + 1) * (delay_max - delay_min) / 2 + delay_min`假设归一化范围为[-1, 1]，无法生成低时延值
4. **scaler对象未保存**：训练时使用的scaler对象未被保存，生成时无法进行正确的反归一化

### 具体分析
- **训练时归一化**：使用RobustScaler，输出范围由数据本身决定
- **生成时反归一化**：使用固定范围[-1, 1]的公式，与训练时的归一化逻辑不匹配
- **结果**：生成数据的时延最小值远高于原始数据，无法覆盖低时延范围

## 解决方案

### 1. 保存训练时的scaler对象
- **修改点**：`step2_0_preprocess_data.py`中的保存预处理结果部分
- **改进内容**：
  ```python
  # 保存预处理结果
  np.savez(
      npz_file,
      features=features,
      behavior_ids=selected_behavior_ids,
      behavior_mapping=behavior_mapping,
      delay_scaler_mean_=delay_scaler.center_,
      delay_scaler_scale_=delay_scaler.scale_,
      loss_rate_mapping=loss_rate_mapping,
      valid_loss_values=valid_loss_values,
      sample_length=len(selected_df),
      num_behaviors=num_behaviors,
      delay_norm=selected_delay_norm,
      loss_norm=selected_loss_norm,
      delay_min=valid_df["delay"].min(),  # 添加
      delay_max=valid_df["delay"].max(),  # 添加
  )
  ```

### 2. 修改生成时的反归一化逻辑，使其与训练时匹配
- **修改点**：`generate_and_visualize.py`中的生成数据部分
- **改进内容**：
  ```python
  # 加载训练时使用的scaler参数
  scaler_mean = data["delay_scaler_mean_"][0]
  scaler_scale = data["delay_scaler_scale_"][0]
  
  # 正确的反归一化逻辑（与RobustScaler匹配）
  # RobustScaler的逆变换公式：x = x_scaled * scale + center
  delay = delay_norm * scaler_scale + scaler_mean
  
  # 确保非负
  delay = np.clip(delay, a_min=0, a_max=None)
  ```

### 3. 修复step2_2_generate_samples.py中的反归一化逻辑
- **修改点**：`scripts/step2_2_generate_samples.py`
- **改进内容**：
  ```python
  # 加载训练时使用的scaler参数
  scaler_mean = data["delay_scaler_mean_"][0]
  scaler_scale = data["delay_scaler_scale_"][0]
  
  # 正确的反归一化逻辑
  delay = generated[:, 0] * scaler_scale + scaler_mean
  
  # 确保非负
  delay = np.clip(delay, a_min=0, a_max=None)
  ```

### 4. 优化生成数据的后处理
- **修改点**：生成数据后的处理部分
- **改进内容**：
  ```python
  # 确保生成数据覆盖原始数据的时延范围
  original_min = self.selected_df["delay"].min()
  original_max = self.selected_df["delay"].max()
  
  # 限制生成数据的范围不超过原始数据范围的合理倍数
  delay = np.clip(delay, a_min=original_min * 0.8, a_max=original_max * 1.2)
  ```
