# 优化生成数据质量和行为类别分布

## 问题分析

1. **行为类别分布单一**：所有有效样本都被分配了行为类别2，缺乏多样性
2. **行为标签与窗口数量不匹配**：导致需要截断行为标签
3. **行为标签中包含大量噪声**：大部分行为标签是-1（噪声）
4. **生成数据极端值问题**：出现0.0的时延值和1000+ms的极端值
5. **样本选择逻辑不合理**：没有考虑行为类别的分布

## 优化方案

### 1. 优化行为模式发现
   - 调整HDBSCAN的参数，减少噪声标签数量
   - 增加行为类别的多样性
   - 优化特征提取，提高聚类效果

### 2. 改进样本选择逻辑
   - 确保选择的样本序列包含多种行为类别
   - 实现智能样本选择，优先选择行为类别丰富的连续序列
   - 增加样本选择的灵活性，支持多种选择策略

### 3. 优化生成约束
   - 在生成过程中添加合理的约束，避免极端值
   - 利用训练数据的实际分布指导生成过程
   - 平衡数据多样性和真实分布

### 4. 改进行为标签扩展
   - 优化从窗口级别到样本级别的行为标签扩展逻辑
   - 确保每个样本都有正确的行为标签
   - 处理边界情况，减少未分配标签的数量

### 5. 增强数据分布指导
   - 在训练过程中保存真实数据的分布信息
   - 生成时使用这些信息作为约束条件
   - 增加数据分布的验证和调整

## 实现步骤

1. **修改pattern_identifier.py**：优化HDBSCAN参数，减少噪声标签
2. **修改step2_2_generate_samples.py**：实现智能样本选择，优先选择行为类别丰富的连续序列
3. **修改diffusion_model.py**：优化生成约束，避免极端值
4. **修改step2_0_preprocess_data.py**：改进行为标签扩展逻辑
5. **修改train_diffusion_model.py**：保存训练数据的分布信息
6. **运行端到端流程**：验证优化效果

## 预期效果

- 行为类别分布更加多样化，不再只有单一类别
- 生成数据的极端值减少，分布更接近真实数据
- 样本选择更加智能，优先选择行为类别丰富的序列
- 行为标签扩展更加准确，减少未分配标签的数量
- 生成数据的质量和多样性得到提升

1. **行为模式发现参数调优**：降低HDBSCAN的min_samples参数，减少噪声标签
2. **智能样本选择**：实现基于行为类别多样性的样本选择算法
3. **生成约束优化**：在生成过程中添加基于训练数据分布的约束
4. **行为标签扩展改进**：优化从窗口级别到样本级别的映射逻辑
5. **数据分布指导**：利用训练数据的实际分布来约束生成过程

## 验证方法

1. 分析行为类别分布，确保多样性
2. 检查生成数据的统计特性，确保接近真实数据
3. 验证样本选择是否包含多种行为类别
4. 运行端到端流程，评估整体效果
5. 可视化生成数据和原始数据的对比

通过这些优化，我们可以提高生成数据的质量和多样性，使其更接近真实网络数据的分布，同时包含更丰富的行为类别。
